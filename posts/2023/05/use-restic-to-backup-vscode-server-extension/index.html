使用 restic 备份 vscode server 的扩展

2023年5月8日05:26
阅读时长: 2 分钟

在 vscode 中是可以自动同步配置 Settings Sync ，但是暂时没法同步 vscode server 中的扩展，导致每次重装 rpi4 上的 vscode server 时需要手动安装扩展。

分析

在之前的 restic 备份中是忽略了整个 vscode server 文件备份的 ~/.vscode-server，因为

  1. 直接备份 ~/.vscode-server/extensions 会导致备份过大
  2. restic 的排除规则不像 gitignore，无法在包含被排除的目录中的文件

但是现在可以解决这些问题了

  1. 在 ~/.vscode-server/extensions/extensions.json 中保存了当前安装的所有扩展 package 信息，可以在 Extension Marketplace Command line extension management 中找到从命令行中安装方法 code --install-extension (<extension-id> | <extension-vsix-path>)
