如何在 Raspberry Pi 4 中配置网络

2026年1月2日20:54
阅读时长: 2 分钟

最近我的 raspberry pi4 在晚上进入 ssh 重启后没管，直到第二天早上发现无法连网才知道系统挂了，我尝试过使用 sudo fsck.ext4 -fy /dev/sdc2 修复 root ext4 文件系统，以前这种情况也出现过，但这次不知道是什么情况，在我的 nas, wsl2 不同的系统上挂载 SD 卡修复通过也还是无法启动，也尝试过修复 /boot 分区 sudo fsck.vfat /dev/sdc2 选择 2) Copy backup to original 也没用，最后没办法，尝试使用 restic 备份恢复 /boot 分区，不出意外的也没用，甚至还有些文件不见了，看来 restic 对于这种情况还是不适合的，只有完整的系统备份才有效吧！raspberry pi4 的 SD 卡还是太脆弱了，这种情况不少见，没办法只能重装系统了，正好 debian 13 trixie 最近发布可以升级 Raspberry Pi OS: View release notes 。

由于目前我的 rpi4 设备是作为旁路由存在的，新系统的首要任务就是在无 DHCP 网络环境中配置静态 IP 方便使用。之前在 raspberrypi/rpi-imager 工具安装系统到 SD 卡时会有静态 IP 的配置，但在最近的 v2.0.0: A new Imager 更新后发现没有了这个选项，在 Allow static IP address configuration in “OS Customisation > General” #1215 这个问题中提到 Use link-local addresses if you have no DHCP server 这个方法可以访问无 DHCP 的 rpi4 设备，但目前未测试过（希望不会有这个机会），我是使用 HDMI 显示直接在物理机操作。

参考 raspberrypi doc: Assign a static IP address 建议应该在路由器中配置 IP，这与我的需求不合，参考 raspberrypi doc: Networking 中使用 nmcli 通过 NetworkManager 配置网络，其中的 FAQ 提到在 DNS configuration for NetworkManager 使用配置文件。偶然发现 nmtui 命令行交互工具，相比 nmcli 更方便，也不需要 GUI 环境。

参考 Where does Network Manager store settings? 使用下面的命令查看配置文件
