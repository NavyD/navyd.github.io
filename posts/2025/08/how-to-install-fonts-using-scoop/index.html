如何使用 scoop 安装字体

2025年8月29日16:03
阅读时长: 5 分钟

在使用 scoop 安装字体 nerd-fonts 后尝试更新时总是会遇到字体文件无法访问的问题 Copy-Item : The process cannot access the file 'C:\Users\navyd\AppData\Local\Microsoft\Windows\Fonts\CaskaydiaCoveNerdFont-BoldItalic.ttf' because it is being used by another process. ，与 Updating font fails on Windows 10 (21H2) #271 中的描述一致。

分析

由于之前是 scoop 全局安装的字体，不使用用户级字体安装原因参考 Weird behavior for installed fonts after Windows 11 22H2 update #198 ，并且 scoop 目前已经可以在用户目录正常安装字体，不再需要管理员权限！

在这里直接尝试使用 scoop 移除字体时发现字体被许多程序占用，无法卸载！

检查占用字体句柄的进程

使用 windows 资源监视器查看什么进程打开了这些字体。经过简单的测试发现，如果在 windows terminal 中未包含中文字体时不会打开相关的中文字体句柄，首次出现中文字符才会打开相关字体句柄。

微软官方应用 Process Explorer （安装命令 winget install Microsoft.Sysinternals.ProcessExplorer 注意重启终端后执行命令 procexp）也可以查看文件句柄。

另外还可以使用 System Informer 查看打开文件句柄的进程，响应更快。

注意：这 2 个应用要显示子进程树形列表可以点击 Process, Name 列来切换显示方式，参考 filtering multiple same processes to single process #1091 。

可以发现有许多进程如 chrome, obsidian, windows terminal 等常用的应用都在使用这个字体，需要手动关闭这些进程，但棘手的是 windows terminal 作为系统自带的终端，执行 powershell 等 CLI 命令需要在终端执行，这就不可能执行 scoop 卸载命令前关闭 windows terminal ，这是个死循环！！

参考 Updating font fails on Windows 10 (21H2) #271 提到需要使用额外的终端软件运行 scoop 命令即可。

Note that updating the font from a console which uses the font still failed with the same error. I think this is expected. I just had to start a cmd.exe or another shell not using that font, and then the update went through without error. Similar to when updating pwsh or WindowsTerminal, I’ll have to keep an eye out using scoop status when there is an update to the font, and update it in another shell instead of the one I use normally which uses the font.

注意：

  • 目前执行 cmd.exe 会启动 windows terminal ，需要安装第三方终端如 alacritty 以避免使用需要移除的字体文件。
  • 在执行 scoop 卸载命令前需要关闭所有使用相关字体的进程。

解决

通过系统设置卸载（首选、最安全）

在设置界面中只能单个删除字体

可以使用 旧字体控制面板界面 或进入 C:\WINDOWS\Fonts 批量删除字体

在安全模式下删除

未使用！！！

使用命令强制删除（高级方法）

对于在可用字体中无法查找到的但存在于 ~\AppData\Local\Microsoft\Windows\Fonts 中的字体文件，在 explorer.exe 中无法删除提示 操作无法完成，因为文件已在 System 中打开。请关闭该文件并重试 时，可以使用 管理员权限 运行命令强制删除相关字体文件

1

Remove-Item -Force -Path "C:\Users\navyd\AppData\Local\Microsoft\Windows\Fonts\Sarasa*.ttf"

注意：确保你删除的是正确的字体文件，误删系统字体会导致显示问题。

总结

由于 windows 系统的限制，使用 scoop 管理字体相对比较麻烦，一旦字体需要更新，所有使用这些字体的进程都需要关闭才能正常更新。

如果使用 scoop update -a 更新字体时未成功应用到系统，可以关闭所有相关进程后强制重新安装 scoop update -f SarasaGothic-SC 即可。
