在 Lua 中获取返回状态和程序输出

2025年3月31日13:18
阅读时长: 2 分钟

在对 nvim 配置使用 lua-language-server （简称 luals）检查时需要获取 $VIM and $VIMRUNTIME 用于配置 workspace.library 以加载 vim.xxx 库通过类型检查。

在 luas ls 配置文件 .luarc.lua 中通常有下面的配置

---@type _.lspconfig.settings.lua_ls.Lua
---@diagnostic disable: missing-fields
return {
  runtime = { version = "LuaJIT" },
  workspace = {
    checkThirdParty = false,
    library = {
      vim.env.VIMRUNTIME,
      -- lazy.nvim 插件目录
      data_dir .. "/lazy",
      -- Depending on the usage, you might want to add additional paths here.
      "${3rd}/luv/library",
      "${3rd}/busted/library",
    },
  },
}

这里的 vim.env.VIMRUNTIME 在只能在 neovim 中运行才能使用，如果仅用在 lua ls 时不存在 vim 全局变量导致 vim 类型检查无效。考虑到 neovim 的安装路径不同，需要执行 VIMRUNTIME="$(nvim --clean --headless --cmd 'echo $VIMRUNTIME|q')" 才能确定。

那么有什么方式在 lua 中执行命令获取输出呢？

分析

在 Lua os.execute return value 中提到可以使用 io.popen 中执行命令获取输出。在 Get back the output of os.execute in Lua 中提到需要处理尾空格的问题。

1
2
3
4
5
6

local handle = io.popen(command)
local s = handle:read("*a")
handle:close()
s = string.gsub(s, "^%s+", "")
s = string.gsub(s, "%s+$", "")
s = string.gsub(s, "[\n\r]+", " ")

注意跨平台时 cmd 解析的问题：在 io.popen 是由 C 标准库的 popen() 实现，在 unix 上默认使用 sh -c cmd 执行命令，而在 windows 中的 _pclose 上提到 _popen 默认使用的是 cmd.exe /c cmd

在 Getting return status AND program output 提到从 lua 5.2 开始可使用 file:close () 返回值

local handle = io.popen(final_cmd .. " 2>&1", "r")
if not handle then
  return nil
end

local output = handle:read("*a")
local ok, reason, status = handle:close()

-- 判断执行状态
if ok and reason == "exit" and status == 0 then
  return output:gsub("[\r\n]+$", "") -- 去除尾部换行
else
  return nil
end

注意：为了兼容性同时在 neovim 和 lua ls 运行，在 .luarc.lua 中只能使用 lua 5.1 特性！

有一个简单的方法是仅获取到输出后不检查返回值，只检查这个输出是否存在即可。但目前 lua 标准库中不存在路径相关 API，需要依赖 luafilesystem 提供了完善的支持，这是个比较简单的判断，不需要复杂的处理，参考 Check if directory exists in lua?

--- Check if a file or directory exists in this path
function exists(file)
  local ok, err, code = os.rename(file, file)
  if not ok then
    if code == 13 then
      -- Permission denied, but it exists
      return true
    end
  end
  return ok, err
end
