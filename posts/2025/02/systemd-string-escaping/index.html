在 Systemd Unit 中转义字符

2025年2月21日16:12
阅读时长: 1 分钟

在 systemd.unit 中的 ExecStart 有时会使用 shell 执行命令，就会出现字符串转义的问题。

watchexec -vv \
    --emit-events-to none \
    --fs-events create,modify,remove,rename \
    --filter '**/common/*' \
    # 禁用首次启动时运行命令 \
    --postpone \
    # 等待时发现有新的事件时重启 \
    --on-busy-update restart \
    # 事件等待间隔 \
    --debounce 10s \
    --shell none \
    -- sh -euxc '\
        sleep 120; \
        is_running="$(docker ps -q -f name=photoprism -f status=running)"; \
        [ -z "$is_running" ] && docker start photoprism; \
        docker exec -u "$(id -u):$(id -g)" photoprism photoprism index -c; \
        [ -z "$is_running" ] && docker stop photoprism;'

参考 String Escaping for Inclusion in Unit Names

The escaping algorithm operates as follows: given a string, any “/” character is replaced by “-”, and all other characters which are not ASCII alphanumerics, “:”, “_” or “.” are replaced by C-style “\x2d” escapes. In addition, “.” is replaced with such a C-style escape when it would appear as the first character in the escaped string.

使用 systemd-escape 命令可以将 '' 单引号中内容转义：

$ cat <<'EOF'
"hello world'
EOF

$ cat <<'EOF' | xargs -0 --no-run-if-empty systemd-escape
"hello world'
EOF
\x22hello\x20world\x27\x0a

$ systemd-escape 'echo \"hello world\"'
echo\x20\x5c\x22hello\x20world\x5c\x22

[Service]
ExecStart=/usr/bin/zsh -c 'watchexec -vv \
    --emit-events-to none \
    --fs-events create,modify,remove,rename \
    --filter "**/common/*" \
    # 禁用首次启动时运行命令 \
    --postpone \
    # 等待时发现有新的事件时重启 \
    --on-busy-update restart \
    # 事件等待间隔 \
    --debounce 10s \
    --shell none \
    -- sh -euxc \x27\
        sleep 120; \
        is_running="$(docker ps -q -f name=photoprism -f status=running)"; \
        [ -z "$is_running" ] && docker start photoprism; \
        docker exec -u "$(id -u):$(id -g)" photoprism photoprism index -c; \
        [ -z "$is_running" ] && docker stop photoprism;\x27'
