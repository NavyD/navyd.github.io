阅读时长: 2 分钟

解决

目前只能使用 restic backup / 备份 C:/ ，而其它盘无法备份，除非使用 restic backup c:/dir1 d:/dir2 这种指定顶层目录的方式以匹配排除规则 */* ，再使用 restic rewrite 将目录重写参考 Windows include/exclude not working #5177

总结

目前 restic windows 备份存在许多路径问题
