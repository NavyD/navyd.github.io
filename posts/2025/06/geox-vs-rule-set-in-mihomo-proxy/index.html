geox VS rule-set in mihomo proxy

2025年6月15日11:50
阅读时长: 1 分钟

在 mihomo 配置文件中使用分流规则时有 2 种方式：

  • geox
  • rule-set

在 MetaCubeX/meta-rules-dat 中提供了常用的分流规则集合并支持这 2 种使用方式，那么问题来了，应该选择哪种方式？

对比

可维护性

在 sing-box/Deprecated Feature List/1.8.0 中提到

GeoIP

The maxmind GeoIP National Database, as an IP classification database, is not entirely suitable for traffic bypassing, and all existing implementations suffer from high memory usage and difficult management.

Geosite

Geosite, the domain-list-community project maintained by V2Ray as an early traffic bypassing solution, suffers from a number of problems, including lack of maintenance, inaccurate rules, and difficult management.

在 mihomo 虚空终端 Docs/快捷配置/Stash(私货) 推荐使用的是 rule-set

# ...
rule-providers:
  private:
    <<: *domain
    url: "https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/meta/geo/geosite/private.list"
  cn_domain:
    <<: *domain
    url: "https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/meta/geo/geosite/cn.list"

rule-set 相比 geox 更加灵活，简单。在 geox vs rule-set: MetaCubeX 对二者的态度？ #949 维护者回复到不会移除 geox 特性！

可靠性

rule-set 对比 geox 有一个巨大的优势是不需要在配置文件中使用 geox-url 代理 github 访问以避免启动时下载出错。

geox-url:
  geoip: "https://mirror.ghproxy.com/https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/geoip-lite.dat"
  geosite: "https://mirror.ghproxy.com/https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/geosite.dat"
  mmdb: "https://mirror.ghproxy.com/https://github.com/MetaCubeX/meta-rules-dat/releases/download/latest/country-lite.mmdb"
  asn: "https://mirror.ghproxy.com/https://github.com/xishang0128/geoip/releases/download/latest/GeoLite2-ASN.mmdb"
