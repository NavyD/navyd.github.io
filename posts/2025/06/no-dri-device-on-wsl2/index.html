在 WSL2 中无法找到 /dev/dri 设备

2025年6月2日13:48
阅读时长: 1 分钟

今天尝试在 WSL2 中启动 immich 时发现由于未找到 /dev/dri 设备失败！

1
2
3
4
5

$ docker compose up -d
[+] Running 1/2
 ✔ Container immich_machine_learning           Running                                                         0.0s
 ⠋ Container immich_machine_learning_openvino  Starting                                                        0.0s
Error response from daemon: error gathering device information while adding custom device "/dev/dri": no such file or directory

分析

在前一阵都可以正常启动的容器怎么会出现问题呢，打开 windows store 发现这狗给我偷偷更新了：

1

3

$ wsl --version
WSL 版本: 2.5.7.0
内核版本: 6.6.87.1-1
WSLg 版本: 1.0.66
MSRDC 版本: 1.2.6074
Direct3D 版本: 1.611.1-81528511
DXCore 版本: 10.0.26100.1-240331-1435.ge-release
Windows: 10.0.26100.4061

在 microsoft/WSL 中发现 2.5.1 breaks /dev/dri detection - Hardware acceleration is dead #12702 提供了详细的分析，只需主动加载 vgem 模块即可：sudo modprobe vgem

解决

由于每次启动后都需要主动加载模块太麻烦，参考 2.5.1 breaks /dev/dri detection - Hardware acceleration is dead #12702 issuecomment-2739170962 在 /etc/modules-load.d/vgem.conf 添加内容以在启动时自动加载 vgem 模块：

vgem
