POSIX

在 debian/wiki/locale 提供了字符集相关的配置，这里使用 Standard 的方式配置。注意：在 dpkg-reconfigure locales TUI 界面移动到最后找到并使用空格选中 [*] zh_CN.UTF-8 UTF-8 回车确认后，选择 en_US.UTF-8 作为默认的字符集以避免终端出现中英文混合的问题。

1

sudo dpkg-reconfigure locales

配置完 locale 后再查看编码

1
2
3
4
5
6

$ locale -a
C
C.utf8
en_US.utf8
POSIX
zh_CN.utf8

docker

如果使用的是 postgres 容器可以参考 locale customization ，运行 localedef -i zh_CN -c -f UTF-8 -A /usr/share/locale/locale.alias zh_CN.UTF-8 或使用 Dockerfile 构建新的镜像：

1
2
3
4

FROM postgres:15
RUN localedef -i zh_CN -c -f UTF-8 -A /usr/share/locale/locale.alias zh_CN.UTF-8
# 可选 默认中文
ENV LANG zh_CN.utf8
