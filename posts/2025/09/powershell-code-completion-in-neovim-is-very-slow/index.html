2025年9月14日16:20

我发现在 WSL2 的 neovim 中编辑 ps1 文件发现仍然存在相同的问题，但在 linux debian 主机上却不存在这个问题，那么这可能是 windows 环境的问题。

Windows

对于 windows 上的 neovim 上面的方法都无效，移除了所有的环境变量也没用！我尝试切换 blink.cmp 为 nvim-cmp 后发现 powershell 补全工作正常，确定是 blink.cmp 的配置问题！

目前安装的 blink.cmp 版本为 v1.6.0 ，回退到 v1.5.1 即可。

解决

使用下面的配置将 blink.cmp 的版本固定到 ~1.5.1 。

1
2
3
4
5

  return jit.os == "Windows" and {
    "saghen/blink.cmp",
    optional = true,
    version = "~1.5.1",
  } or {},

但在我写这篇文章的时候 blink.cmp v1.7.0 发布，虽然不知道是什么原因，经过测试发现这个问题已被解决！
